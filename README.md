# سایه‌های دربار
نسخه‌ی اولیه‌ی آنلاین بازی استنتاج اجتماعی با تم قاجاری.

## اجرا
```bash
npm install
npm start
```
سپس `http://localhost:3000` را باز کنید.

## Render
یک Web Service بسازید، Build Command: `npm install` و Start Command: `npm start`.

## نکته
این نسخه هسته‌ی آنلاین، اتاق، چت، نقش مخفی، رأی‌گیری، سیاست و reconnect دو دقیقه‌ای را فراهم می‌کند. برای نسخه‌ی production باید احراز هویت، persistence، rate limit و validation سمت سرور تکمیل شود.
